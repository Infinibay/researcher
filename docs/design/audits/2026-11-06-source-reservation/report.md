# Cierre de preparación y nueva adopción

Se mantiene la referencia elegida de Repositorios, sin otra ronda de conceptos.
La preparación real se detuvo antes del commit inicial; después el propietario
creó un archivo y un commit independientes. Desde la web se cerró su reserva,
se perdió deliberadamente la respuesta y una recarga recuperó el estado original.
La nueva adopción fue una decisión separada, conservando HEAD, configuración,
inode y contenido. Otra sesión retomó una reparación guardada usando exactamente
su clave original, sin admitir previamente otro trabajador.

Pasaron cuatro capturas de escritorio/móvil, sin errores JS, desbordamiento
horizontal ni incidencias Axe en header/workbench. Hubo un POST de cierre,
uno de nueva adopción y uno de reparación. El journal terminó con cuatro grants
reales retirados y cero ejecuciones nativas. [Evidencia](evidence.json).

El primer verificador se detuvo al buscar la etiqueta exacta «Operación» en un
select cuya etiqueta incluía las opciones. Se conservó el mismo servidor y cierre,
se comprobó el formulario por lectura y se continuó con el locator de combobox.
No se repitió el cierre ni se recrearon las operaciones para completar el ensayo.

La revisión visual confirma que se distingue carpeta conservada de fuente
registrada. La densidad de rutas, encuadres de captura y actualización de la lista
lateral se mantienen en el pulido diferido. Esta entrega no acepta toda la página.
