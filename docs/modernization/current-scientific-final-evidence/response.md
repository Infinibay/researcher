Un **porcentaje** describe una proporción: 78 % equivale a 78 de cada 100. Los **puntos porcentuales** expresan la resta entre porcentajes: pasar de 78,00 % a 82,57 % supone 4,57 puntos porcentuales más. Eso no demuestra que cambiar de tratamiento produzca ese beneficio.
