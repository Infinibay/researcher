# Entrega documental acotada entre tareas

Una dependencia documental aceptada podía bloquear a su sucesor: el resultado
admite2MiB y se copiaba entero en una entrada nativa limitada a1MiB. El esquema4
guarda descriptores pequeños y ofrece lecturas exactas del paquete, informes y
entrada histórica mediante `researcher_prerequisite_research`.

Las lecturas conservan las comprobaciones de alcance, contexto, evidencia y
aceptación; no crean otro loop ni otorgan aprobación o publicación. Las entregas
ya preparadas con esquema2/3 mantienen sus bytes. La política común7 explica
que referencias y lectura no prueban comprensión, y conserva identidades2–6.
[Contrato y ejemplo](../architecture/predecessor-research-material.md).

## Pendientes funcionales

El transporte acotado no garantiza que analizar un paquete completo grande
quepa en los límites de herramientas/tokens. Faltan acceso selectivo a fuentes
y limitaciones, contexto original del plan y continuaciones voluminosas.
Las entregas históricas grandes conservan el límite; necesitan una nueva
entrega explícitamente autorizada para adoptar el formato nuevo.

No se declara comprensión humana, calidad de un modelo real, aceptación integral
de páginas ni nueva suite global verde. Permanecen42escenarios amplios abiertos
y0/12páginas plenamente aceptadas. No se consumió ningún turno generativo.
Los detalles secundarios siguen reservados para después de las tareas principales.
